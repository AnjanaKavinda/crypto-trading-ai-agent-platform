# Version Registry

Version and retain provenance for:
- Strategy and parameters
- Model and provider
- Prompt/template
- Agent configuration
- Dataset and source mapping
- Feature/indicator definition
- Validation methodology
- Risk model and risk policy
- Safety policy
- Contract/schema
- API
- Application release
- Infrastructure/configuration
- Experiment

A historical trade or validation result must resolve to the exact versions used at that time. New logic means a new version; never mutate historical meaning in place.

# State Machine Registry

## Signal lifecycle
DRAFT -> CANDIDATE -> QUALIFIED -> RISK_PENDING -> APPROVAL_PENDING -> APPROVED -> EXECUTION_READY -> EXECUTED -> MONITORING -> CLOSED -> EVALUATED.
Alternative terminal states: REJECTED, NO_TRADE, EXPIRED, SUPERSEDED, CANCELLED.

## Approval lifecycle
PENDING -> APPROVED / REJECTED / MODIFIED / EXPIRED / CANCELLED. Modification invalidates previous approval and requires revalidation.

## Execution lifecycle
DRAFT, PENDING_APPROVAL, APPROVED, PRE_EXECUTION_VALIDATION, READY_TO_EXECUTE, SUBMITTING, SUBMITTED, PARTIALLY_FILLED, FILLED, CANCEL_PENDING, CANCELLED, REJECTED, FAILED, EXPIRED, RECONCILING, RECONCILED, UNKNOWN.

## Strategy lifecycle
DRAFT, EXPERIMENTAL, BACKTESTED, OOS_VALIDATED, WALK_FORWARD_VALIDATED, SHADOW, PAPER, PRODUCTION, RETIRED, REJECTED.

## System readiness
INITIALIZING, READY, DEGRADED, RESTRICTED, BLOCKED, EMERGENCY_STOP, RECOVERY, UNKNOWN.

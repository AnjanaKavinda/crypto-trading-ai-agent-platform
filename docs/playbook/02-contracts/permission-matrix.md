# Permission Matrix

## Permission categories
READ_MARKET_DATA, READ_ACCOUNT, ANALYZE, PROPOSE_SIGNAL, RUN_BACKTEST, CALCULATE_RISK, REQUEST_APPROVAL, APPROVE_TRADE, CREATE_EXECUTION_INTENT, SUBMIT_ORDER, CANCEL_ORDER, RECONCILE, DEPLOY_STRATEGY, MANAGE_SECRETS.

## Rule
Research users/agents do not automatically receive execution permissions. AI agents must not receive unrestricted exchange credentials or fund-transfer permissions.

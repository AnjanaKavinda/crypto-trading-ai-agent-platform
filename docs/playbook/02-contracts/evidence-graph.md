# Evidence Graph

## Purpose
Trace every conclusion from raw data and source information to analysis, strategy conditions, qualification, risk, approval, execution, outcome, and learning.

## Graph flow
```text
Source -> Raw Data -> Data Quality -> Feature -> Analytical Finding -> Evidence Item -> Strategy Condition -> Signal Qualification -> Validation Result -> Risk Proposal -> Approval Decision -> Execution Intent -> Order/Trade -> Trade Outcome -> Experience -> Learning Insight
```

## Evidence categories
Technical, structure, SMC, Wyckoff, volume, order flow, liquidity, derivatives, on-chain, fundamental, tokenomics, sentiment, narrative, macro, intermarket, volatility, regime, event risk, historical, agent evidence, risk evidence, execution evidence, conflicting evidence, limitations.

## Independence rule
Confluence must be based on independent evidence streams. Correlated indicators, shared data sources, shared models, or repeated prompts must not be counted as independent confirmations.

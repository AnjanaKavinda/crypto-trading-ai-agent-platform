# Adaptive Intelligence, Experience, Learning and Self-Awareness

## Objective
Add controlled experience learning, performance awareness, uncertainty awareness, and governed improvement without bypassing safety or human control.

## Learning lifecycle
Observe -> Record -> Experience -> Evaluate -> Identify Pattern -> Form Hypothesis -> Experiment -> Validate -> Govern -> Version -> Shadow/Paper Test -> Production Eligibility -> Observe Again.

## Experience record
References market snapshot, market context, strategy version, signal, validation result, risk proposal, approval decision, execution, trade outcome, agent outputs, system awareness, timestamp, and provenance.

## Performance evaluation
Track agent accuracy, calibration, false positives, false negatives, regime performance, asset performance, timeframe performance, drift, reliability. Track strategy win rate, expectancy, profit factor, drawdown, Sharpe, Sortino, MAE, MFE, regime/asset/timeframe performance, drift, reliability.

## Self-awareness
Operational self-awareness means the system can report what it knows, what it does not know, data reliability, agent health, strategy health, validation freshness, risk state, execution health, learning state, uncertainty, limitations, and unknowns.

## Governance
Learning cannot directly execute trades, modify production strategies, rewrite prompts, or promote challenger models. Changes require hypothesis, experiment, validation, governance, versioning, and shadow/paper evaluation before production eligibility.

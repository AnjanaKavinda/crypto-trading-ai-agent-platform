# Analysis and Meta-Analysis Methodology

## Objective
Transform validated data into structured market context without making final trading or execution decisions.

## Four-category crypto analysis framework
1. Fundamental Analysis: tokenomics, whitepaper/use-case, team, developer activity, partnerships, utility, revenue, TVL, adoption, governance, unlocks, incidents.
2. Technical Analysis: trend, support/resistance, price action, chart structure, VWAP, volume profile, indicators, volatility, market structure, SMC, Wyckoff, Fibonacci.
3. On-Chain Analysis: network activity, exchange flows, whale activity, holder distribution, realized/unrealized metrics, stablecoin flows, security metrics.
4. Sentiment Analysis: news, social media, Fear & Greed, funding as crowding proxy, narrative momentum, abnormal social activity.

## Institutional technical indicator taxonomy
- Volume/structure: VWAP, volume profile, POC, HVN/LVN, volume confirmation, order-flow imbalance.
- Trend: EMA, SMA, Ichimoku, ADX, trendlines.
- Momentum: RSI, MACD, stochastic, divergences.
- Volatility/risk: ATR, Bollinger Bands, volatility compression/expansion.
- Market structure: HH/HL/LH/LL, BOS, CHoCH, liquidity zones.

## Indicator metadata contract
Every indicator should define category, purpose, inputs, timeframe, lagging/leading nature, best regimes, weak regimes, failure modes, output schema, and how it contributes to evidence.

## Analysis boundaries
Chat 5 asks: What is the market doing? It does not generate final signal qualification, position size, human approval, or execution.

## Output
MarketContext, AnalysisSnapshot, EvidenceItems, ConfluenceAssessment, ConflictAssessment, AdversarialAssessment, EventRiskAssessment, and AnalyticalUncertainty.

# Frontend, Dashboard and Trader UX

## Objective
Design the professional trader-facing user experience while keeping backend services authoritative.

## UI principle
The frontend displays, requests, configures, approves, rejects, and monitors. It must never independently calculate critical trading decisions.

## Primary areas
Overview, markets, AI analysis, signals, trade approval, positions, portfolio, orders, strategies, backtesting, risk, AI agents, system health, alerts, audit, settings.

## Required displays
Trading status, safety state, exchange status, market data health, active alerts, evidence report, historical validation, conflicts, adversarial assessment, NO_TRADE reasons, risk proposal, editable parameters, revalidation status, approval record, execution state, position state, audit trail, system awareness.

## Trader-facing methodology explanations
The UI should explain Fundamental, Technical, On-Chain, and Sentiment analysis categories; indicator purpose; confluence independence; evidence freshness; and why a signal is qualified, rejected, expired, or NO_TRADE.

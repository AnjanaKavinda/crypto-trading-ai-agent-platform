# Four-Agent Team Overview

Human Owner = Product Owner + final architect/merge authority.

1. **Platform Architect** — architecture/ADRs/contracts/traceability/sequencing.
2. **Backend/Foundation Engineer** — deterministic platform/backend/infrastructure.
3. **Trading Intelligence Engineer** — market intelligence/analysis/orchestration/strategy/validation.
4. **QA/Security/Review Agent** — independent testing/security/safety/compliance review.

Core workflow: Architect boundary -> implementation agent -> QA review -> human merge -> traceability update.

Never treat these software-development agents as the runtime trading agents described by Chat 3 of the playbook.

# Start Here — Pre-Implementation Completion

This package contains **183 planned GitHub issues** covering governance through live-readiness governance.

Before creating issues:
1. Put the authoritative full-source playbook at `docs/playbook/**`.
2. Copy the cross-cutting package into `docs/cross-cutting/**`.
3. Copy `.github/**` and `AGENTS.md` from this team package to repository root.
4. Commit/merge specification-only changes to `main`.
5. Review `ISSUE-CATALOG.md`.
6. Create labels (`scripts/create-labels.ps1`).
7. Use `scripts/create-issues.ps1 -DryRun` first.
8. Create the backlog only after the human owner verifies titles/order.
9. Execute **Issue 001 only** first.

Do not run multiple implementation agents before architecture discovery and baseline governance issues are reviewed.
